# Enduro-v2 — железо и распиновка

Кастомная приборка мотоцикла на **Arduino Pro Micro 5V / 16 MHz (ATmega32U4)** с круглым дисплеем **GC9A01** и чтением сигналов штатной панели **Janxin M178A-005-1P**.

## Состав

| Узел | Назначение |
|------|------------|
| Arduino Pro Micro 5V/16 MHz | контроллер |
| GC9A01 240×240 | круглый TFT |
| ~~CHMCU-2317 (MCP23017)~~ | **снят** — передачи на GPIO Pro Micro |
| PC817 8-канальный модуль | гальваническая развязка RPM / дальнего / +12V сигналов |
| Janxin M178A-005-1P | штатная приборка / источник сигналов |

Питание Arduino пока от **USB**. Питание от борта (+12V после зажигания) ещё не разведено.

## Штатная приборка Janxin M178A-005-1P

Разъём **18 pin, 2×9**.

Фото корпуса, жгута Tyco и места на байке: **[M178-CONNECTOR.md](M178-CONNECTOR.md)** (`docs/photos/`).

Ориентация (как смотрим на разъём со стороны проводов — уточнять по меткам корпуса **10 / 2 / 18 / 9**):

```
верхний ряд:  10  11  12  13  14  15  16  17  18
нижний ряд:    1   2   3   4   5   6   7   8   9
```

### Распиновка — 2 ряда (зелёный и чёрный сверху)

Вид со стороны проводов. **Верх** = pin 1…9 (зел. GND + чёрн. +12V). **Низ** = pin 10…18.

|--|-------|-------|-------|-------|-------|-------|-------|-------|-------|
| **ВЕРХ** | GND масса | N нейтраль | +12V зажиг. | HB дальний | NC | NC | NC | ? | ? SPEED? |
| цвет | зелёный | бирюз.+борд. | **чёрный** | синий | — | — | — | зелёный | жёлтый |

| | **10** | **11** | **12** | **13** | **14** | **15** | **16** | **17** | **18** |
|--|--------|--------|--------|--------|--------|--------|--------|--------|--------|
| **НИЗ** | Gear 1 | Gear 2 | Gear 3 | Gear 4 | Gear 5 | Gear 6 | RPM тахо | ? | NC |
| цвет | розовый | син.+борд. | бирюз.+чёрн. | жёлт.+красн. | фиолет. | коричн.+бел. | син.+коричн. | **красный** | — |

Полный список и фото: [M178-CONNECTOR.md](M178-CONNECTOR.md).

### Датчик передач

Работает **замыканием соответствующего провода на массу** (pin 1).

| Передача | Pin |
|----------|-----|
| N | 2 |
| 1 | 10 |
| 2 | 11 |
| 3 | 12 |
| 4 | 13 |
| 5 | 14 |
| 6 | 15 |

На выбранной передаче сопротивление к массе низкое, около **0.100 кОм**.  
На остальных линиях — высокое сопротивление / обрыв.

> Чтение передач: `src/gear_inputs.h` — GPIO **D2…D8** (без MCP).

### RPM (pin 16)

Pin 16 подтверждён как тахосигнал: Arduino через оптрон успешно видит обороты.

**Подключать pin 16 напрямую к Arduino нельзя** (уровни / гальваника борта).

## Развязка RPM через PC817

Используется 8-канальный модуль **PC817** (вход 3.3–30 V). Канал 1:

### Сторона мотоцикла (вход оптрона)

| M178 | PC817 |
|------|--------|
| pin 16 (RPM) | IN1 |
| pin 1 (GND) | GND входной стороны |

### Сторона Arduino (выход оптрона)

| PC817 | Pro Micro |
|-------|-----------|
| OUT1 / V1 | **D0** (`INPUT_PULLUP`) |
| GND_out | Pro Micro GND |

**Важно:** для RPM/SPEED/HB через оптрон входная сторона PC817 на массе байка; выходная — на GND Arduino. Для прямого чтения передач (D2…D8) нужна **общая GND** борт↔Arduino.

Interrupt: `FALLING` на D0 (см. `src/rpm.h`, `src/rpm.cpp`).

## Arduino Pro Micro — каноническая распиновка (FW 1.5+)

Цель: **одно устройство → один край платы**, контакты подряд.

```
        USB
   _____|_____
RAW           TX 1
GND           RX 0     ← RPM D0 / SPEED D1 (PC817) сверху справа
RST           GND
VCC           GND
A3 (свободен)  2 Gear1 ┐
A2 TFT BLK     3 Gear2 │
A1 TFT RES     4 Gear3 │  Жгут «байк»
A0 TFT DC      5 Gear4 │  D2..D9 подряд
15 TFT SCK     6 Gear5 │
14 (NC)        7 Gear6 │
16 TFT MOSI    8 N     │
10 TFT CS      9 HB    ┘  ← дальний PC817
```

| Край | Устройство | Пины подряд |
|------|------------|-------------|
| **Правый** | Байк: передачи + HB (+ RPM/SPEED выше) | **D0…D1**, **D2…D9** |
| **Левый низ** | Дисплей GC9A01 | **A2…A0**, **15**, *(14 NC)*, **16**, **10** + **VCC/GND** |

### Таблица сигналов

| Pin | Назначение |
|-----|------------|
| **D0** | RPM ← PC817 |
| **D1** | SPEED ← PC817 |
| **D2…D7** | Gear 1…6 (M178 10…15) |
| **D8** | Neutral (M178 pin 2) |
| **D9** | High Beam ← PC817 |
| **A0** | TFT DC |
| **A1** | TFT RES |
| **A2** | TFT BLK (`digitalWrite HIGH`, PWM на A2 нет) |
| **A3** | свободен |
| **D14** | NC в ленте дисплея (можно не соединять) |
| **D15 / D16 / D10** | TFT SCK / MOSI / CS |
| **GND / 5V** | общая земля с байком + питание TFT (USB) |

CHMCU-2317 / MCP23017 **не используется**.

## Передачи на GPIO (без MCP)

| M178 | Сигнал | Pro Micro |
|------|--------|-----------|
| 10 | 1 | **D2** |
| 11 | 2 | **D3** |
| 12 | 3 | **D4** |
| 13 | 4 | **D5** |
| 14 | 5 | **D6** |
| 15 | 6 | **D7** |
| 2 | N | **D8** |
| 1 | GND | **GND** |

Активный **LOW**, `INPUT_PULLUP`. Код: `src/gear_inputs.h`.

### High Beam / RPM / SPEED — только PC817

| Борт | PC817 | Arduino |
|------|--------|---------|
| pin 16 RPM | ch1 | **D0** |
| pin 9 SPEED? | ch2 | **D1** |
| pin 4 дальний +12 V | ch3 | **D9** |
| pin 1 GND | GND_in | GND_out → **GND** |

### Pull-up на передачах

Короткие провода: `INPUT_PULLUP` Arduino достаточно. Длинный жгут / помехи — внешние **4.7–10 kΩ** к 5V. Не сильнее 1 kΩ.

### Общая земля

N/1–6 → масса мотоцикла. Прямое подключение к D2…D8 требует **общей GND**. Полная гальваническая развязка при этом теряется (вариант «всё через PC817» — запасной).

**Никогда:** +12 V (pin 3, pin 4, лампы) напрямую на Arduino.

## Калибровка RPM

Константа в `src/rpm.h`:

```cpp
const float RPM_PULSES_PER_REV = 1.0f;  // placeholder — откалибровать
```

Формула в коде:

```text
RPM = frequency_Hz × 60 / RPM_PULSES_PER_REV
```

### Порядок калибровки

Сравнить показания Arduino со штатным тахометром M178 в точках:

| Цель RPM (штатный) | Записать Hz с Serial/экрана |
|--------------------|-----------------------------|
| ~2000 | … |
| ~3000 | … |
| ~4000 | … |
| ~5000 | … |

Оценка импульсов на оборот:

```text
RPM_PULSES_PER_REV ≈ (Hz × 60) / RPM_штатный
```

Усреднить по нескольким точкам и прописать в `rpm.h`.  
На экране «RPM TEST» уже выводятся: filt RPM, raw, Hz, pulse count, age.

Serial (115200): блоки `RPM TEST` каждые ~500 ms (`RPM_SAMPLE_INTERVAL_MS`).

## Свободные / запасные ресурсы

- **A3**, **D14** — свободны (D14 удобно оставить дыркой в ленте дисплея).
- Свободные каналы PC817 — поворотники / лампы +12 V.
- Неизвестные пины M178: **8, 9, 17** — не трогать до идентификации.
- I2C (аппаратный D2/D3) сейчас занят Gear1/Gear2 — расширитель не вернуть без ремапа.
